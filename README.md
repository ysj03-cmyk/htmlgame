# 우리 일상 속 숨은 사회연대경제 제품 찾기

지금까지 수정한 최종 배포본(버전 32)을 GitHub Pages에 올릴 수 있도록 정리한 정적 웹 프로젝트입니다. 별도의 설치·빌드 과정 없이 실행됩니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 전체 디자인·반응형 스타일
- `game.js`: 게임, 제품 위치·크기, 점수, 순위, 입력 검증, 결과 화면 동작
- `assets/`: 네 배경, 시작 화면, 공통 제품 이미지, QR, 글꼴
- `LICENSES/`: 포함된 글꼴의 라이선스
- `SOURCE_VERSION.txt`: 원본 버전과 소스 커밋
- `.nojekyll`: GitHub Pages 정적 파일 제공 설정

## GitHub에 업로드하기

1. ZIP을 먼저 압축 해제합니다.
2. 저장소를 만들거나 사용할 저장소를 엽니다.
3. **이 폴더 안의 파일과 `assets`, `LICENSES` 폴더**를 저장소 루트에 업로드합니다. `index.html`이 저장소 루트에 있어야 합니다. ZIP 파일 자체를 업로드하는 방식은 아닙니다.
4. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
5. Branch를 **main**, 폴더를 **/(root)**로 지정하고 저장합니다. 게시가 완료되면 Pages에 표시되는 주소로 접속합니다.

저장소 이름이 붙는 GitHub Pages 주소에서도 작동하도록 리소스 경로는 상대 경로로 유지했습니다.

## 내 컴퓨터에서 실행

`index.html`을 브라우저로 열 수 있습니다. 권장 확인 방법은 이 폴더에서 다음 명령을 실행하고 `http://localhost:8000`으로 접속하는 것입니다.

```bash
python -m http.server 8000
```

게임 이미지·QR·글꼴은 모두 포함되어 있습니다. Google Sheets 기록 전송과 인스타그램·뉴스레터 연결에는 인터넷이 필요합니다.

## 수정 위치

`game.js`의 `CONFIG`에서 게임 시간 등 설정을 바꿀 수 있습니다. 기존 `SHEET_URL`은 원본 서비스의 Google Apps Script 기록 수집 주소를 그대로 유지했습니다. 다른 기록 저장소를 사용할 때만 이 주소를 교체하세요.

- `NAMES`: 제품명
- `PRODUCT_ATLAS_RECTS`: 공통 제품 이미지의 영역
- `BAKED_TARGETS`: 각 배경의 제품 위치·크기
- `SCENE_PIXELS`: 배경의 기준 크기

네 배경은 하나의 `assets/products-shared.png`를 함께 사용합니다. 제품 종류별 이미지가 배경마다 바뀌지 않도록 공통 이미지 구조를 유지하세요. 배경 크기나 제품 위치를 수정할 때는 클릭 영역과 정답 표시도 함께 확인해야 합니다.

## 기록 및 입력

이름과 전화번호 뒤 네 자리를 입력하며, 공개 순위표에는 이름만 표시됩니다. 현재 순위는 기기·브라우저의 로컬 저장소를 기준으로 표시됩니다. 배포 주소가 달라지면 브라우저 로컬 기록도 별도로 시작합니다. 기존 방문자의 개인 입력·기록 데이터는 이 소스 ZIP에 포함되어 있지 않습니다.

## 검증

원본 HTML의 CSS·JavaScript를 내용 변경 없이 분리했으며, 모든 로컬 리소스 경로와 JavaScript 구문을 확인했습니다. GitHub Pages 실제 배포는 사용자의 저장소에 업로드한 후 진행됩니다.
